GTM & CMP Helper - The companion for web analysts and developers

GTM & CMP Helper (formerly "Insert GTM" / "GTM Helper") is a Chrome extension that simplifies debugging Google Tag Manager containers and managing Consent Management Platforms (CMPs).

CORE FEATURES:

1. Intelligent CMP Reset 
Reset consent status with just one click. The extension automatically detects common CMPs (such as Cookiebot, Usercentrics, OneTrust, Borlabs, CMP19, and many more) and specifically deletes the associated cookies and storage entries. Ideal for testing consent banner logic without manually clearing cookies.

2. GTM Container Injection
Inject any GTM container code (GTM-XXXXXX) into any website. Test new tracking setups in live environments before they are implemented in the source code.
- Supports GTM Environments (gtm_auth & gtm_preview).
- GA4 Debugging: Automatically activates GA4 DebugView by passing preview tokens – without needing the official Tag Assistant.
- Flexible positioning in <head> or <body>.

3. Google Tag & Container Detection
Automatically detects Google tags loaded on the current page — always on, no configuration, no extra permissions. Classifies the load method — standard (googletagmanager.com), first-party (server-side GTM / Google Tag Gateway), custom path, or base64 tunnel.

Container count on the toolbar badge, a "Detected Google tags & containers" popup section (ID · method · host), and a console log per new detection.

4. dataLayer Tools
Send dataLayer push events or execute custom JavaScript code on the current page. Perfect for quick testing of event handlers.

5. GTM Workspace Integration
When working in the GTM interface, the Helper detects this and provides a direct link to the Analytrix GTM Checkup to verify your container for best practices. 

6. GTM Interface Comfort
- Submit dialog warning: colors the submit button orange whenever the selected action only creates a version instead of publishing.
- Pinned navigation: navigation stays visible while scrolling long lists instead of scrolling out of view.
- Pinnable search bars: a toggle in the title bar of tag, trigger, and custom variable lists keeps title, search, and buttons at the top while scrolling.
- Sorting for parameter tables: lookup tables, event parameters, and comparable key/value lists can be sorted alphabetically in both directions — by input or output column. 
- Hide built-in variables: a switch permanently collapses the rarely needed list so the user-defined variables are reachable without scrolling.
- Edit variables straight from input fields: when a field of a tag or trigger references {{a variable}}, a chip appears below it. One click opens that variable’s definition directly above the tag, so closing it puts you back where you were instead of in the variable list.
- Everything switchable: each of these features can be turned off on its own — or all at once — in the popup, so nothing collides with other GTM extensions. All on by default.

DESIGN & USABILITY:
- Dark Mode by default (with Light Mode option).
- Available in English and German.

GTM & CMP Helper - Begleiter für Web-Analysten und Entwickler

Der GTM & CMP Helper (ehemals "Insert GTM" / "GTM Helper") ist eine Chrome-Extension, die das Debugging von Google Tag Manager Containern und das Management von Consent Management Plattformen (CMPs) drastisch vereinfacht.

KERNFUNKTIONEN:

1. Intelligenter CMP-Reset 
Setzen Sie den Consent-Status mit nur einem Klick zurück. Die Extension erkennt automatisch gängige CMPs (wie Cookiebot, Usercentrics, OneTrust, Borlabs, CMP19 uvm.) und löscht gezielt die zugehörigen Cookies und Storage-Einträge. Ideal zum Testen von Consent-Banner-Logiken ohne manuelles Löschen von Cookies.

2. GTM Container Injektion
Fügen Sie beliebigen GTM-Container-Code (GTM-XXXXXX) in jede beliebige Website ein. Testen Sie neue Tracking-Setups in Live-Umgebungen, bevor diese im Quellcode implementiert sind.
- Unterstützt GTM Environments (gtm_auth & gtm_preview).
- GA4 Debugging: Aktiviert automatisch die GA4 DebugView durch Übergabe der Preview-Token – ganz ohne den offiziellen Tag Assistant.
- Flexible Positionierung im <head> oder <body>.

3. Google-Tag- & Container-Erkennung
Erkennt automatisch die auf der aktuellen Seite geladenen Google-Tags — immer aktiv, ohne Konfiguration und ohne zusätzliche Berechtigungen. Klassifiziert den Ladeweg — standard (googletagmanager.com), first-party (Server-side GTM / Google Tag Gateway), Custom Path oder base64-Tunnel. 

Container-Anzahl im Toolbar-Badge, eine Popup-Sektion „Erkannte Google-Tags & Container" (ID · Methode · Host) und ein Konsolen-Log pro neuem Fund.

4. dataLayer Tools
Senden Sie dataLayer-Push-Events oder führen Sie benutzerdefinierten JavaScript-Code auf der aktuellen Seite aus. Perfekt für schnelle Tests von Event-Handlern.

5. GTM Workspace Checkup Integration
Wenn Sie in der GTM-Oberfläche arbeiten, erkennt der Helper dies und bietet einen direkten Absprung zum Analytrix GTM Checkup, um Ihren Container auf Best Practices zu prüfen. 

6. Komfort in der GTM-Oberfläche
- Warnung im Sende-Dialog: Färbt den Senden-Button orange, sobald die gewählte Aktion nur eine Version erstellt statt zu veröffentlichen.
- Fixierte Navigation: Bereichsnavigation bleibt beim Scrollen langer Listen sichtbar, statt nach oben wegzuscrollen.
- Fixierbare Suchleiste: Ein Schalter in der Titelleiste von Tags, Triggern und Benutzerdefinierten Variablen hält Titel, Suche und Schaltflächen beim Scrollen oben.
- Sortierung von Parametertabellen: Suchtabellen, Ereignisparameter und vergleichbare Schlüssel-Wert-Listen lassen sich alphabetisch auf- und absteigend sortieren — nach Eingabe- oder Ausgabespalte.
- Integrierte Variablen ausblenden: Ein Schieberegler blendet die selten benötigte Liste dauerhaft aus, damit die benutzerdefinierten Variablen ohne Scrollen erreichbar sind.
- Variablen aus Eingabefeldern heraus bearbeiten: Enthält ein Feld eines Tags oder Triggers eine Referenz wie {{Meine Variable}}, erscheint darunter ein Chip. Ein Klick öffnet deren Definition direkt darüber — nach dem Schließen steht man wieder im Tag statt in der Variablenliste.
- Alles abschaltbar: Jede dieser Funktionen lässt sich einzeln — oder alle zusammen — im Popup abschalten, damit sich nichts mit anderen GTM-Extensions doppelt. Voreingestellt ist alles an.

DESIGN & USABILITY:
- Dark Mode Standard (mit Light Mode Option).
- Vollständig bilingual (Deutsch und Englisch).
